# dev-note

개발하며 마주친 문제와 새로 배운 개념을 기록하는 개인 학습 노트입니다.
단순한 정답보다 **문제 상황, 원인, 해결 과정과 재발 방지 포인트**를 남기는 것을 목표로 합니다.

## 카테고리

| 카테고리 | 내용 |
| --- | --- |
| [Java](./Java/) | Java 문법, JVM, 객체지향, 컬렉션, 동시성 |
| [Spring](./Spring/) | Spring Framework, Spring Boot, JPA, Security |
| [Vue](./Vue/) | Vue, Composition API, 상태 관리, 프런트엔드 |
| [Database](./Database/) | SQL, 데이터 모델링, 인덱스, 트랜잭션 |
| [Git](./Git/) | Git 명령어, 브랜치 전략, 협업 워크플로 |
| [Troubleshooting](./Troubleshooting/) | 개발 중 발생한 오류와 디버깅 기록 |

## 문서 작성 순서

모든 학습 문서는 다음 순서로 작성합니다.

1. 문제
2. 핵심 개념
3. 원인
4. 해결 방법
5. 주의할 점
6. 한 줄 정리

새 문서는 [TEMPLATE.md](./TEMPLATE.md)를 복사해 작성합니다.

## 파일 작성 규칙

- 파일명은 내용을 알아보기 쉬운 영문 kebab-case를 권장합니다.
  - 예: `hashmap-vs-concurrenthashmap.md`
- 하나의 문서에는 하나의 주제를 다룹니다.
- 실행한 명령어, 오류 메시지, 코드와 참고 링크를 가능한 한 함께 기록합니다.
- 해결 후에는 재현 조건과 주의할 점을 다시 확인합니다.
